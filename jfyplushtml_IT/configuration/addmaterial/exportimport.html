Esporta/Importa materiale

Utilizzo del formato di testo

Per esportare i materiali delle giacenze, accedere a factory → sheets, fare clic su Export/Import, selezionare Esporta, scegliere .txt e salvarlo nella cartella di destinazione.

Aprire il file .csv esportato, aggiungere un nuovo materiale grezzo o lamiera con i dettagli necessari, quindi salvare il file.

Per importare il file aggiornato, accedere a factory → sheets →Export/Import, selezionare Importa e scegliere il file TXT modificato. I materiali e le lamiere appena aggiunti verranno visualizzati inJFY Plus.

Utilizzo del formato CSV

  • Fare clic su factory → sheets → Export/Import…​ → ui:EGTag.ExportSheets[Export sheets]. Scegliere il file CSV e salvarlo nella cartella di destinazione.

  • Aggiungere le lamiere e i relativi parametri e salvare il file .csv.

  • Utilizzando Importa lamiere, scegliere il file .csv modificato.

  • Le lamiere e i materiali aggiungi di recente verranno visualizzati inJFY Plus.

Importa materiale deve essere un file di testo con una costruzione speciale che copre il seguente formato. ; Materal-Name=[BendMaterial],[Density],[FName]; RawMaterial-Thickness,[Name]=[Film],[Treatment],[Surface]; Sheet-Width,Height,Grain,Desc,HeatNumber=Qty,[Factory],[Shelf],[Cost],[Comments]

Example: Aluminum0.5,Aluminum-051500,1500,None,=112,,,22,2500,1250,Horizontal,=105,,,7,2500,1500,None,=100

Per creare facilmente un file di importazione, esportare prima i materiali e poi apportare modifiche ad esso o visualizzare la struttura.
