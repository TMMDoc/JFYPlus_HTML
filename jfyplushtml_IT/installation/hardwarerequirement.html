Requisiti porte

Server JFY Plus: 7371

Il server attende le richieste del client su questa porta TCP. Le connessioni in entrata dovrebbero essere consentite su questa porta sul computer server.

Server licenze mobili: 5776

Il server licenze mobili attende le richieste di licenza su questa porta. Le connessioni in entrata dovrebbero essere consentite su questa porta sul computer server licenze mobili (server JFY Plus).

Connessione licenza al cloud: 7567

Questa porta viene utilizzata da Flux (software di piegatura) e dal server licenze mobili per inviare richieste di licenza a Metamation Cloud. Quindi la connessione in uscita dovrebbe essere consentita su questa porta per le attivazioni e i rinnovi delle licenze.

Requisiti di installazione e supporto

  • Privilegi amministratore necessari per installare l’applicazione JFY Plus.

  • Tool di assistenza remota tramite VPN del contractor o connessione sicura.
