Output settings

Save layout NC and reports - Abilitare questa opzione per il salvataggio dell’NC layout e dei report.

Save layout file - Abilitare questa opzione per il salvataggio del file di layout.

Output simulation preview in reports - Abilitare questa opzione per generare l’anteprima della simulazione dell’attrezzaggio insieme agli altri output. È una breve animazione GIF per l’attrezzaggio laser/punzonatura.

Do not delete program outputs on layout/job completion - Abilitando questa opzione si salterà l’operazione di eliminazione per gli output del programma quando un job/layout è stato contrassegnato come completato.

Nest settings

Mix parts from multiple Jobs - Supportare il nesting in modalità mista. I pezzi di più lavori dovrebbero essere annidati insieme per una migliore efficienza di affollamento.

Do not auto-release layouts - Ciò impedirà ai layout di essere disponibili per la produzione fino a quando tutti i layout non saranno in uno stato di rilascio.

Re-nesting packing cut-off - Questo valore viene utilizzato per decidere se un layout annidato viene mantenuto nella coda di approvazione e viene nuovamente annidato quando vengono pianificati pezzi nuovi o questi vengono rilasciati per la produzione. I relativi output vengono esportati nella cartella di output.

Interactive sheet-name prefix - Questa sezione viene utilizzata per supportare il nesting interattivo, in cui l’utente ha un maggiore controllo sui pezzi da annidare e sul risultato del nesting. Utilizzare uno schema di denominazione diverso da quello del nesting automatico per i layout annidati in maniera interattiva.

Update sheet inventory on nest (un)release - Se questa opzione è abilitata, le giacenze lamiere verranno aggiornate all’invio di un nesting alla macchina. Inoltre, richiamando il nesting dalla macchina, la lamiera tornerà tra le giacenze.

Automate remnant inventory management - Quando questo interruttore è selezionato, il software automatizza la gestione giacenze residue. Se non è selezionato, la gestione residui diventa interattiva.

Auto-refresh Out-of-date layouts - Se selezionato, il software aggiorna tutti i layout obsoleti collegati a un pezzo dopo il calcolo delle sue soluzioni di taglio.

Automate twin-line nesting - Selezionare questa opzione per abilitare l’automazione a doppia linea.

Pull workflow settings

late:SH.UsePullWorkflow[Use 'Pull workflow'] - Questa opzione è utile per gli utenti che hanno bisogno di un sistema di pianificazione e nesting altamente autonomo. Se abilitata, Praxis pianifica il nesting su richiesta.

Nests per station - Questo valore serve per impostare quanti layout devono essere creati per stazione.

Maximum sheets per nest - Questo valore viene utilizzato per controllare il conteggio massimo delle lamiere rispetto al nesting unico. Quindi, ad es., se c’è un ordine con un pezzo grande (che riempie l’intera lamiera), necessario in grandi quantità (per esempio, 500), Praxis non crea più un singolo nesting con 500 copie in modalità "pull". Invece, crea 10 copie per nesting, dove 10 è il massimo.

Bend programs per station - Questo valore serve per impostare quanti programmi di piegatura devono essere creati per stazione.

Mark the task completed, when the program outputs are removed - Abilitare questa opzione per contrassegnare un layout come Fatto quando gli output vengono rimossi dalla destinazione di output target.

Spreadsheet import settings

CAD lookup directories - Praxis cerca di caricare la voce del pezzo indicato nel CSV importato dalla libreria pezzi. Tuttavia, se il pezzo non è disponibile nella libreria pezzi, prova a recuperare i pezzi dalle directory di ricerca in base all’ordine delle directory impostate in questa finestra di dialogo.

Use recursive CAD search - Abilitare questa opzione per ripetere la ricerca per i risultati successivi.

Create a blank part for the missing CAD files - Se non esistono pezzi nella libreria o nelle directory di ricerca di Praxis, Praxis crea un pezzo vuoto per i pezzi non disponibili.

Do not show the New Job dialog if the spreadsheet has no error - Se le voci CSV sono pulite, ovvero se non ci sono discrepanze di dati dal DB o tutti i campi sono elencati correttamente, Praxis non mostra la finestra di panoramica del job ed elaborerà il job non appena CSV viene importato o eliminato.

Prefer Raw-Material column over Material + Thickness - Tipi di foglio di calcolo supportati:

  1. Pattern 1: nome del pezzo, quantità, data di scadenza, priorità, materiale grezzo

  2. Pattern 2: nome del pezzo, quantità, data di scadenza, priorità, spessore del materiale

  3. Pattern 3: nome del pezzo, quantità, data di scadenza, priorità, spessore del materiale, materiale grezzo

Se questa opzione non è selezionata, il pattern 1 viene considerato il tipo di foglio di calcolo predefinito. Supportiamo anche il pattern 3 nel caso in cui il formato CSV sia di tipo "pattern 3".

Se questa opzione è selezionata e CSV è di tipo "pattern 2", Praxis risolve il materiale grezzo dai campi Materiale e Spessore CSV.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Selezionare questa opzione per abilitare l’esportazione CSV quando un layout o un job è completo. I report completati vengono salvati nella destinazione Report specificata in Fabbrica → Impostazioni → Impostazioni report.
