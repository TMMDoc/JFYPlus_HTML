Notifiche

Notification settings

Enable email notifications - Questa opzione viene utilizzata per abilitare e configurare le notifiche via e-mail.

Notification recipients - Inserire i dettagli del destinatario; per inserire più di un destinatario usare uno spazio o una virgola per la separazione.

Send messages in batch - Questa opzione viene utilizzata per combinare più messaggi e inviarli in batch. Per evitare messaggi di grandi dimensioni, i messaggi inviati entro un determinato intervallo di tempo definito vengono combinati.

Attach tooling simulation preview where applicable (Warning: Messages may become too large) - Questa opzione aggiunge un’anteprima della simulazione dell’attrezzaggio alla notifica via e-mail.

Mail settings

SMTP server - L’indirizzo del server di posta elettronica SMTP è riportato nella sezione Account o Impostazioni del client di posta dell’utente.

SMTP port - Questa impostazione è lo standard di base che i server di posta elettronica utilizzano per inviarsi e-mail l’un l’altro in Internet.

Transport protocol -

Server needs authentication - Abilitare questa opzione per la convalida del server.

User-name - Inserire qui l’e-mail del destinatario.

Password - Inserire qui la password del destinatario.

Test…​ - Utilizzare l’interruttore Test per verificare se un’e-mail è stata consegnata correttamente all’utente. Viene visualizzato un messaggio di errore, come nell’immagine sottostante, se la prova non ha avuto esito positivo.

La notifica via e-mail non funziona in modalità interattiva. Quindi, la modifica di un pezzo, l’applicazione di una modifica e il salvataggio non genererebbero l’invio di una notifica all’utente, anche se c’è un errore di attrezzaggio/progettazione nel pezzo salvato.
A causa della natura della comunicazione via e-mail, la consegna della posta può essere molto più lenta e quindi viene effettuata in background. Le notifiche possono andare perse se Engine viene arrestato/spento prima che tutti i messaggi vengano consegnati.
