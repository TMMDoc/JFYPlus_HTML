Taglio

Output settings

Save cut outputs - I risultati dell’attrezzaggio vengono salvati solo se l’attrezzaggio è OK; queste impostazioni di esportazione sono abilitate e configurate. Abilitare questa opzione per il salvataggio dell’NC di taglio.

Output tooling simulation preview - Abilitare questa opzione per generare l’anteprima della simulazione dell’attrezzaggio insieme agli altri output. È una breve animazione GIF per l’attrezzaggio laser/punzonatura.

Cut output destination - Questa è la destinazione per il salvataggio dell’NC e di report.

MetaCAM settings

Lookup MetaCAM materials by raw-material names (Enable this for DMM like integrations) - Quando questo stile è abilitato, Praxis genera le pagine in base ai nomi dei materiali grezzi e le assegna ai pezzi al momento dell’attrezzaggio automatico.

MetaCAM sync folders - Questa impostazione di taglio viene utilizzata per aggiungere ulteriori cartelle MetaCAM che devono essere sincronizzate insieme a config.dat quando viene utilizzato il comando config-push monitor. Config-push salva i file locali nel magazzino Praxis, che viene scaricato sugli altri computer all’avvio/riavvio di MetaCAM. Il computer Engine dovrebbe effettuare automaticamente una sincronizzazione quando l’attrezzaggio automatico viene eseguito per una macchina MetaCAM; oltre agli strumenti, alcuni degli altri candidati specifici per l’installazione sono le cartelle Ecc., Report e Macchine.

DMM config sync location - Questa è la posizione per la sincronizzazione della configurazione de Dynamic Machine Management da impostare.

Flux Settings

Enable multi-pass nesting - Ciò consente al laser di tagliare più volte sullo stesso contorno (soluzione preferita per materiale più spesso).
