Part Validation

CAD Error

Infeasible (Bend and Cut)

  • JFY Plus assigns Bend Infeasible state to the part if no valid bend solution is found during the auto tooling.

  • If the Bend solution [08.07] have warning which will be ignored automatically considered for Cut solution.

  • The part is put in Cut infeasible state if no feasible cutting solution is found.

Material error

  • Material missing : Initially thickness read from model and material assigned which is checked against the JFY Plus Raw Material. If not exists, then it is assigned material missing error.

  • _Material not assigned : Model does not have map field against material, then it is assigned with Material not assigned.

Geometry Error

  • Open contours detected : CAD has open entity.

  • Multiple outer contours detected : CAD has multiple closed loops.

  • Nascent : Loading part from spreadsheet csv or xlsx, missing CAD files are created as Nascent Part error.

  • Geometry missing : CAD does not have valid geometry or not available.

CAM Error

Bend Tooling Error

Following are the bend tooling errors.

  • Collisions detected and Gripper error.

  • Tool Overload error and Hole near bendline.

  • Needs review and Die/Punch span short.

  • Tool missing , Poor backguage , Part too big for Machine.

Cut Tooling Error

Following are the cut tooling errors.

  • Missing cut condition not mapped against Raw Material.

  • Slug Error : For Punch tooling, inner loop is tooled without any joints.

  • Untooled or partially tooled contours : Missed punch tooled segments.
