Beobachten

Watch settings

Enable 'Live Folder' - Legen Sie diese Option fest, um den Live-Ordner zu aktivieren.

Watch this folder - Legen Sie dies als den Ort fest, an dem Praxis beobachten wird.

Watch sub-folders also - Aktivieren Sie diese Option, damit Praxis auch Unterordner innerhalb des oben angegebenen Speicherorts überprüfen kann.

After File Import

After import - Nachdem die Datei importiert wurde, hat der Benutzer zwei Optionen: Die Datei kann vom Speicherort gelöscht oder an einen anderen Speicherort verschoben werden.

Move files to this folder - Wenn die oben genannte Option gewählt werden soll, die Datei an einen anderen Speicherort zu verschieben, geben Sie hier den Speicherort ein, an den die Datei verschoben werden soll.

Move spreadsheets with errors to this folder - Wenn in einer Tabelle Fehler festgestellt werden, kann sie an einen anderen Ort verschoben werden, der in diesem Abschnitt angegeben werden kann.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Aktivieren Sie diese Option, damit Praxis Tabellenblätter importieren kann, die sich im Speicherort des Live-Ordners befinden.

Do not import spreadsheet with errors - Aktivieren Sie diese Option, damit Praxis keine Tabellenblätter mit Fehlern importiert. Sie können an einen zum Bearbeiten anderen Ort verschoben werden, wie oben angegeben.

Spreadsheet import option - Diese Option kann einen Standardimporttyp festlegen, der je nach Ihrer verfügbaren Lizenz eine der folgenden Optionen sein kann.

  • Jobs importieren

  • Aufträge importieren

  • Baugruppen importieren
