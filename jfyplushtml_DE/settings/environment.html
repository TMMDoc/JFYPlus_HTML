Environment settings

Program default units - The user can choose whether the default unit is mm or inch.

Decimal places to display - This value is to set how many decimal places are to be shown.

Decimal accuracy in export/import - Mit diesem Wert wird festgelegt, wie viele Dezimalstellen beim Import oder Export genau sein sollen.

Display part toolings in groups - Verwenden Sie diese Option, um die Werkzeuggruppe für die Anzeige des Rüststatus in der Teilebibliothek auszuwählen.

Captions for command-bar icons - Enabling this option will give a caption under each icon to reference what the page will refer to. When this option is disabled, all captions for the switches are removed and just the icon for each different page is displayed.

Display Job status labels - Wenn Sie diese Option aktivieren, wird die Anzahl der Teile, die sich innerhalb eines Jobs befinden, am Ende der Jobstatusleiste angezeigt. Wenn diese Option deaktiviert ist, wird die Teileanzahl entfernt und die Farbe zur Anzeige des Prozesses bleibt erhalten.

Display nested parts by job-order color - Diese Option zeigt die verschiedenen Teile innerhalb eines Jobs in verschiedenen Farben an. Wenn Sie diese Option deaktivieren, werden alle Teile in der gleichen grauen Farbe angezeigt.

Display the duration in time-span format (HH:MM:SS) - Aktivieren Sie diese Option, um die Dauer im Format HH:MM:SS anzuzeigen. Wenn diese Option aktiviert ist, wird die Dauer in den Layoutdetails und den Job-/Layoutberichten im ausgewählten Format angezeigt. Aufgrund des beschränkten Platzes wird die Dauer auf den Layoutkacheln in einem kompakteren Sekundenformat angezeigt.
