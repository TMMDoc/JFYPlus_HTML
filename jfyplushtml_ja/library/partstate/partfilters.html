部品フィルター

部品ライブラリフィルターを使用すると、特定の条件を適用して、ライブラリ内の部品をすばやく検索して見つけられます。基準を満たす部品のみに結果を絞り込むことで、これらのフィルターは関連する部品を効率的に管理してアクセスしやすくします。

State

  • State フィルターを使用して、部品を現在の状態に基づいて検索します。

  • ドロップダウンには、利用可能なライブラリ部品に応じて、適用可能なすべての状態が表示されます。

  • 状態のリストは、選択した部品とそのステータスに応じて動的に変化します。

  • たとえば、Material Missing を選択して、未解決の材料状態の部品を表示します。

Status

  • Status フィルターを使用して、部品をツーリングステータスに基づいて検索します。

  • ドロップダウンには、ツーリング状態が色付きのボックスとして表示され、利用可能なすべてのマシンとその適用可能なエラーが表示されます。

  • 色付きのボックスは次の状態を表します。

    • 白: ツーリング OK

    • オレンジ: ツーリングにエラーがある

    • 黄: ツーリングに警告がある

    • グレー: ツーリングが抑制されている

  • 部品に narrow flange または tooling not assigned エラーがある場合、これらを選択するとそれぞれの部品が表示されます。

  • 選択したマシンでツーリングが抑制されている部品は、グレーのボックスをクリックすることで表示されます。

Bend mounts

  • Bend mounts フィルターを使用して、使用される曲げ工具に基づいて部品を検索します。

  • ドロップダウンには利用可能なすべての曲げ工具が表示され、工具名、タイプ（punch、gooseneck、radius など）、または説明でフィルターできます。

  • 複数の工具を選択して Match all をクリックし、選択した両方の工具を使用する工具を並べ替えます。

Used tools

  • Used tools でのフィルタリングは、Bend mounts でのフィルタリングと同様に機能します。

  • 工具アイコンは比例サイズ（正確ではなく相対的）で表示されます。

  • ツーリングプレビューが開いているとき、フィルターリスト内の工具にマウスを合わせると、プレビューペインでその工具が強調表示されます。

  • 複数の工具を選択し、Match all を使用して適用できます。
