レポート

レポート

Report settings

Report destination - このオプションを使用して、レポートを保存する場所を指定します。

Report Output Format - エクスポート時のレポートの形式を指定します（PDF または HTML）。

Job report settings

Include layout images in the report - この設定を有効にすると、レポートにレイアウトの画像が含まれます。

Include part images in the report - この設定を有効にすると、レポートに部品の画像が含まれます。

Include layout reports in the job report - この設定を有効にすると、job レポート内の layout レポートにリンクされます。

Label report settings

Enable label reports - この設定を有効にすると、job またはレイアウトからラベルを生成できます。それぞれ右クリックして Export Layouts または Send to Machine を選択すると、label レポートを表示するオプションが表示されます。

Label size (W x H) - ラベルの幅と高さをミリメートル単位で指定します。これらの値は、生成されるラベルの物理的寸法を定義します。

QR code field - ラベルの QR コードにエンコードするデータフィールドを定義します。ドロップダウンリストには、Part Name、Part Order、None が含まれます。選択されたフィールド値が QR コードとして表示されます。

Barcode field - ラベルのバーコードにエンコードするデータフィールドを定義します。ドロップダウンリストには、Part Name、Part Order、None が含まれます。選択されたフィールド値がバーコードとして表示されます。

Show part image - 有効にすると、生成される label レポートに部品画像が含まれます。
