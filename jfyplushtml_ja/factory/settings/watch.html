監視

Watch Settings を使用すると、JFY Plus は指定されたフォルダーを監視し、ファイルを自動的にシステムにインポートできます。これにより、手動介入なしで Parts、Jobs、Assemblies、Orders のインポートを自動化できます。

Watch settings

Enable 'Live Folder' - 指定されたフォルダーの自動監視を有効にします。

Watch this folder - 受信ファイルを監視するフォルダーを指定します。

Watch sub-folders also - すべてのサブフォルダーを監視プロセスに含めます。

After file import

After import - ファイルがインポートされた後、ユーザーには 2 つのオプションがあります。ファイルは、その場所から削除するか、別の場所に移動できます。

  • Delete imported file - インポートが成功した後、ソースファイルを削除します。

  • Move imported file - インポートが成功した後、ソースファイルを Move files to this folder で指定されたフォルダーに移動します。

Move files to this folder - After import が Move imported file に設定されている場合に、正常にインポートされたファイルを移動する宛先フォルダーを指定します。

Move spreadsheets with errors to this folder - 失敗したインポートを指定されたエラーフォルダーに移動します。

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - watch フォルダーで検出されたスプレッドシートファイルを自動的にインポートします。

Do not import spreadsheet with errors - 検証エラーを含むファイルのインポートを防ぎます。

Spreadsheet import option - ドロップダウンからインポートするデータの種類を選択します。サポートされているスプレッドシート形式には、CSV、XLSX、XML が含まれる場合があります。利用可能なオプションは次のとおりです:

  • Import Jobs - スプレッドシートから job データをインポートします。

  • Import Orders - スプレッドシートから order データをインポートします。

  • Import Assemblies - スプレッドシートから assembly データをインポートします。

  • Import Parts - スプレッドシートから part データをインポートします。

追加情報

  • watch フォルダーを構成する際は、UNC パス (\\ServerName\FolderPath) またはマップされたドライブ (M:\FolderPath) を使用してください。C:\FolderPath などのローカルパスは使用しないでください。

  • JFY Plus Engine サービスを実行しているコンピューターは、構成された watch フォルダーへの読み取りおよび書き込みアクセス権を持っている必要があります。十分な権限がないと、ファイルが正常に検出、インポート、移動、または削除されない場合があります。

  • Watch Settings を有効にする前に、スプレッドシートマッピングを構成する必要があります。そうしないと、JFY Plus は watch フォルダーで検出されたスプレッドシートファイルを処理できません。
