編集

Edit オプションを使用すると、JFY Core 内のマシン、材料、工具、システム設定に関連するさまざまな設定を変更できます。選択すると、JFY Core の適切な構成セクションにリダイレクトされ、必要な調整を行うことができます。

次の設定を編集できます:

  • Machines

  • CAM Materials - JFY Core のドキュメントの Database → Materials トピックを参照してください。

  • Bend-tool Inventory - JFY Core のドキュメントの Database → Bend Tools トピックを参照してください。

  • Custom Bend Deductions - JFY Core のドキュメントの Database → Bend Deductions トピックを参照してください。

  • JFY Core Settings - JFY Core のドキュメントの Settings トピックを参照してください。
