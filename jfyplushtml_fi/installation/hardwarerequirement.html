Porttivaatimukset

JFY Plus Server : 7371

Palvelin odottaa asiakasohjelman pyyntöjä tässä TCP-portissa. Saapuvat yhteydet tulee sallia tähän porttiin palvelintietokoneessa.

Floating License Server : 5776

Kelluvan lisenssin palvelin odottaa lisensointipyyntöjä tässä portissa. Saapuvat yhteydet tulee sallia tähän porttiin kelluvan lisenssin palvelintietokoneessa (JFY Plus-palvelin).

Lisenssiyhteys pilveen : 7567

Tätä porttia käyttävät JFY Core (särmäysohjelmisto) ja kelluvan lisenssin palvelin lähettääkseen lisensointipyyntöjä Metamation Cloud -palveluun. Lähtevä yhteys tulee siis sallia tässä portissa lisenssien aktivointeja ja uusintoja varten.

Asennus- ja tukivaatimukset

  • JFY Plus-sovelluksen asentamiseen vaaditaan järjestelmänvalvojan oikeudet.

  • Etädiagnostiikkatyökalut urakoitsijan VPN:n tai suojatun yhteyden kautta.
