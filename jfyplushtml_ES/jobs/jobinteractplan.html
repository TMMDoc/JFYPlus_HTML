Anidamiento interactivo

El nesting interactivo se puede utilizar para crear un plan de nesting para una sola pieza, algunas piezas de una tarea, una sola tarea o varias tareas. Le permite seleccionar máquinas y materiales, establecer parámetros de la chapa y revisar los resultados del nesting de forma interactiva.

Haga clic con el botón derecho en una pieza o en una tarea y seleccione la opción Plan Part…​/Plan Job…​ → Run Interactive Nesting…​.

  • Se abre la ventana Interactive Nesting.

  • De forma predeterminada, la ventana de nesting interactivo cambia a la página Select Machine & Material.

  • Las máquinas se muestran con barras de color que indican la carga de producción disponible:

    • Barra verde: horas programadas

    • Barra gris: horas disponibles (de un turno de 8 horas)

  • Debajo de cada máquina, las piezas seleccionadas se agrupan con su materia prima (piezas/cantidad total).

  • Si una pieza no tiene una solución de utillaje válida para una máquina, esa pieza y ese material se ignoran para el procesamiento en una máquina determinada.

  • Si se selecciona una materia prima para una máquina, no estará disponible para otras máquinas.

  • Una vez establecido el plan de nesting de la máquina, seleccione la chapa preferida y anule los parámetros de la chapa como Priority, Quantity, Margins, etc.

  • Puede filtrar las chapas para mostrar All Sheets, Standard Sheets o Remnant Sheets. Haga clic en Next.

No es posible aumentar las cantidades en esta fase. Puede mantener la misma cantidad que el inventario de la chapa o reducirla y comprobar los resultados del nesting.

  • Update Qty aparece en la ventana del plan de nesting interactivo.

  • De forma predeterminada, Pick All (F5) incluye todas las piezas para el nesting, o puede seleccionar manualmente las piezas prioritarias y ajustar las cantidades de piezas. Haga clic en Next.

  • El nesting comienza y las piezas anidadas en la chapa se actualizan con el estado de color azul.

  • La carga de producción de la máquina se actualiza según el resultado del nesting.

  • Los diseños anidados se dibujan a escala y se muestran en la pestaña Nest Results.

  • Si algunas piezas quedan sin anidar, aparece el mensaje Some parts remain unnested; estas piezas permanecen en la tarea original.

    • El motivo por el que no se anidan puede ser que no haya chapa disponible para anidar

  • Los resultados del nesting interactivo llevan el prefijo: factory → settings → Job→ Nest settings, Interactive sheet-name prefix.

  • Los diseños de nesting interactivo llevan el prefijo con la letra L.
