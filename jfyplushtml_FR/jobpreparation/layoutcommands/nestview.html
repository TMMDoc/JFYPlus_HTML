Affichage de layout

La sélection de l’option Imbrication affiche une liste de toutes les imbrications qui se trouvent actuellement dans la tâche sélectionnée, vous pouvez alors effectuer un double clic sur une imbrication pour en voir le détail ou un clic droit sur l’imbrication pour voir des options supplémentaires.

Après avoir double-cliqué sur une imbrication, vous verrez d’abord les pièces utilisées ainsi que des informations détaillées sur l’imbrication, comme les matières utilisées, le temps de cycle et d’autres métriques.

Vous pouvez cliquer pour faire défiler les différentes imbrications disponibles et également cliquer sur une pièce pour utiliser la même interaction que celle mentionnée dans la zone des pièces.

Un clic droit sur une imbrication affiche des options supplémentaires.

  • « Envoyer à la machine » libère l’imbrication pour la production sur les machines, dès lors l’option devient à « Rappeler depuis la machine ».

  • « Ajouter des pièces » permet d’ajouter des pièces supplémentaires à l’imbrication.

  • « Adapter / Compacter» vous permet de modifier par lot les matières ou les machines utilisées dans l’imbrication.

  • « Modifier le TTL » vous permet d’appliquer une technologie laser différente pour la matière et l’épaisseur sélectionnées dans l’imbrication.

  • « Diviser les layouts » vous permet de prendre une imbrication qui contient plusieurs répétitions et de créer une nouvelle imbrication.

  • « Renommer » vous permet de renommer l’imbrication.
